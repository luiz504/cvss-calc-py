# References

## CVSS

- [CVSS v3.1 specification](https://www.first.org/cvss/v3.1/specification-document): the formulas and metric weights, including `Roundup`
- [CVSS v3.1 user guide](https://www.first.org/cvss/v3.1/user-guide): how to choose each metric value
- [CVSS v3.1 examples](https://www.first.org/cvss/examples): scored real-world vulnerabilities, handy as test vectors
- [FIRST CVSS v3.1 calculator](https://www.first.org/cvss/calculator/3.1): the official calculator, to cross-check results
- [NVD CVSS v3 calculator](https://nvd.nist.gov/vuln-metrics/cvss/v3-calculator): the NIST calculator, to cross-check results
